# SearchX - Fast and Smart Search Engine

## Project Overview
SearchX is a simple search engine built using HTML, CSS, JavaScript, Python, and Node.js.

## Features
- Minimalist user interface
- Search box for query input
- Results display (Coming soon)

## Hosting
Frontend hosted on [GitHub Pages](https://your-github-username.github.io/SearchX).
Backend deployed on [Heroku](https://searchx-backend.herokuapp.com) (example).

## Instructions to Run Locally
1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/SearchX.git
    cd SearchX
    ```
2. Install dependencies and run the backend:
    ```bash
    npm install
    node server.js
    ```
3. Open `index.html` in your browser.
